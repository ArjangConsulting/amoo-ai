# ``AmooCore``

Shared protocols and data types for AI-driven mobile testing on iOS and Android.

## Overview

Amoo connects local AI clients and command-line workflows to platform drivers, on-device
companions, and a recording-to-test pipeline. Start with the architecture guide to understand
those boundaries before exploring individual API symbols.
